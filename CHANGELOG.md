# Changelog

Notable changes to `aisdk/klingai`. Release notes are also published at https://github.com/phpaisdk/klingai/releases.

## v0.10.2 — 2026-10-29

- Bound TTS audio downloads and reject unsafe remote destinations.
- Requires `aisdk/core ^0.10.2` at release.

## v0.10.0 — 2026-10-29

### What's new

- Request and response support for the 0.10 SDK, including the new agent, failover, caching and decision APIs in `aisdk/core`.

### Compatibility

- Works with `aisdk/core ^0.10.0` and `aisdk/openai-compatible ^0.10.0` where applicable. Upgrade SDK packages together.

## Earlier releases

See the [GitHub releases](https://github.com/phpaisdk/klingai/releases) for versions before 0.10.0.
